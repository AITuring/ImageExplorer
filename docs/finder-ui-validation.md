# Finder 风格界面回归检查（2026-10-30）

本轮包括通高侧边栏、紧凑工具栏/列表、底部路径栏、浅深色材质、方形应用图标，以及菜单交互修复。

## 已修复

- 右键子菜单通过 Portal 独立挂载，避免父菜单 backdrop-filter 和 overflow 裁切。
- 保留 Radix 指针事件传播，菜单关闭不依赖退出动画，消除已关闭菜单残留。通用 Dialog 及遮罩也移除退出动画，避免文件简介关闭后保留焦点锁定。
- 文件拖拽忽略菜单内容，避免 Portal 事件触发文件拖动。
- 清晰度开关增加文字及明确提示；原分析算法和持久化键保持不变。独立预览环境曾关闭该开关，已通过真实 ARW 验证开启后标签恢复。
- 分析进度移至独立紧凑状态行，避免挤占工具栏；窄内容区收缩辅助控件。
- 光圈及焦距消除浮点尾数，新增回归测试。
- 设置选项改为可聚焦按钮，提供展开状态和 Escape 关闭。
- 前端 Tauri API 固定到 2.11.1，与 Rust 2.11.5 的主次版本对齐；更新插件恢复锁文件规定的 2.9.0。

## 验证

- ESLint 无错误，保留既有 FileGalleryView/TanStack Virtual React Compiler 警告。
- 7 项前端测试通过，TypeScript/Vite 构建通过。
- 实际 Tauri 窗口：排序子菜单展开、选择大小后重开验证勾选、恢复名称排序、Escape 关闭；打开方式子菜单展开。
- 真实照片目录：清晰度标签及焦点区域恢复，分栏/画廊切换，光圈显示 f/6.3。
- 实际 release 应用包：启动、浅色主题及恢复跟随系统、设置关闭、列表切换、新建/关闭标签页。
- 本地打包命令：`pnpm tauri build --bundles app --config '{"bundle":{"createUpdaterArtifacts":false}}'` 成功；应用包 ICNS 与源码资源 SHA-256 一致。

## 验证边界

本轮没有执行删除、移动原始照片等破坏性操作，也没有对所有 RAW 清晰度结论进行人工准确率验收。默认更新包发布仍需要真实的更新公钥及签名私钥；本地构建覆盖配置未改动发布配置。构建保留既有 window-vibrancy 重复符号警告，实际应用可启动。
